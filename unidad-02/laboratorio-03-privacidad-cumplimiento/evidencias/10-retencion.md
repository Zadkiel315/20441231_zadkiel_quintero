# LAB-03 - Politica de retencion de datos

## 1. Objetivo

Analizar por que no es buena idea guardar todos los datos de los clientes para siempre y que se debe tomar en cuenta para decidir cuanto tiempo conservarlos.

## 2. Procedimiento

### Actividad 10 - Politica de retencion

La organizacion propone conservar todos los datos de los clientes indefinidamente porque podrian ser utiles en el futuro.

**Pregunta 1. Es compatible con el principio de minimizacion?**

No, porque se estarian guardando datos sin tener claro si todavia son necesarios. Lo mejor seria conservar solamente la informacion que se necesita y durante el tiempo que corresponda.

**Pregunta 2. Que riesgos genera conservar informacion innecesaria?**

Se acumulan datos que podrian quedar expuestos si ocurre un ataque o un acceso no autorizado. Tambien se vuelve mas dificil administrar la informacion y aumenta el riesgo de que se utilice para algo que no corresponde.

**Pregunta 3. Que deberia determinar la organizacion antes de establecer un periodo de retencion?**

Deberia revisar para que se recopilaron los datos, cuanto tiempo se necesitan, si existen obligaciones que requieran conservarlos y cuando dejan de ser utiles para la actividad.

**Pregunta 4. Que informacion deberia documentarse para justificar el periodo seleccionado?**

Se deberia documentar la finalidad de los datos, el tiempo que se decidio conservarlos, la razon de ese periodo, quien autorizo la politica y que se hara con la informacion cuando ya no sea necesaria.

## 3. Resultado

Se identifico que conservar los datos indefinidamente puede generar riesgos y que es importante establecer un periodo de retencion segun la finalidad y las necesidades de la organizacion.

## 4. Analisis

Guardar informacion por si algun dia sirve no parece una buena razon para conservarla para siempre. Es mejor tener una politica clara para saber que datos se necesitan, cuanto tiempo deben mantenerse y cuando corresponde eliminarlos o aplicar otro tratamiento autorizado.

## 5. Conclusion

La organizacion debe tener una politica de retencion que explique cuanto tiempo conservar los datos y por que. Esto ayuda a evitar que se acumule informacion innecesaria y permite administrar mejor los datos de los clientes.
